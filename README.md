# Syd & Dan’s Wish List

A shared wish list for Syd and Dan, with a place for friends and family to keep track of gifts they’ve bought.

[Open the wish list](https://dfree951.github.io/wishlist/)

Browse both lists together or filter by person. Each item includes a store link, photo, price, and any notes about size or preferences. You can check other stores or compare prices before choosing a gift.

Mark gifts purchased to help avoid duplicates. For items with a quantity, record how many you bought; the list shows how many are still wanted. Some items welcome unlimited purchases.

Syd and Dan can sign in to add or edit items, choose photos, and import an Amazon wish list. Purchase details stay hidden in their editing view so gifts can remain a surprise.
